# reader-first/sentence-load

A sentence combines enough length, clauses, labels, or asides to overload the main point.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Document context
- Category: Reading load

Compares evidence across a paragraph, nearby sentences, or the complete document.
