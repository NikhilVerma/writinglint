# ai-style/outline-conclusion

A canned “challenges and future prospects” ending instead of a specific conclusion.

- Default level: `info`
- Confidence: `low`
- Evidence source: Document context
- Category: Chatbot voice

Compares evidence across a paragraph, nearby sentences, or the complete document.
