# reader-first/undefined-decision-stack

The document accumulates decision standards such as relevant or sufficient without saying how a reader or system should apply them.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Document context
- Category: Reading load

Compares evidence across a paragraph, nearby sentences, or the complete document.
