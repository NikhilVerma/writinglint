# reader-first/relationship-pileup

A passage rapidly changes the relationships among a small set of participants.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Dependency graph
- Category: Reading load

Matches grammatical relationships between words, not only their order or part of speech.
