# reader-first/noun-pile

Four or more common nouns are stacked together without showing how they relate.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Dependency graph
- Category: Jargon

Matches grammatical relationships between words, not only their order or part of speech.
