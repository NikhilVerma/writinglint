# ai-style/referential-compression

Several nearby sentences open with bare pronouns instead of carrying the subject forward explicitly.

- Default level: `info`
- Confidence: `low`
- Evidence source: Dependency graph
- Category: Uniform rhythm

Matches grammatical relationships between words, not only their order or part of speech.
