# ai-style/passive-voice-density

Several nearby sentences rely on passive voice, making the process harder to follow.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Document context
- Category: Hidden or false agency

Compares evidence across a paragraph, nearby sentences, or the complete document.
