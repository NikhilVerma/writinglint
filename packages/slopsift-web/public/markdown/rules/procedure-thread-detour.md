# reader-first/procedure-thread-detour

Three numbered steps leave an output unused for one step and then resume it, suggesting that the middle step interrupts the procedure handoff.

- Default level: `info`
- Confidence: `low`
- Evidence source: Dependency graph
- Category: Reading load

Matches grammatical relationships between words, not only their order or part of speech.
