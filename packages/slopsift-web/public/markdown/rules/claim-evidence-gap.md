# ai-style/claim-evidence-gap

Nearby prose stacks outcome claims without measurements, sources, examples, or a mechanism.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Dependency graph
- Category: Vague attribution

Matches grammatical relationships between words, not only their order or part of speech.
