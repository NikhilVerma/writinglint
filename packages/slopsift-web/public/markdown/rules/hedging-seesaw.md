# ai-style/hedging-seesaw

Relentless “While X… However, Y” balancing, a position never taken.

- Default level: `info`
- Confidence: `low`
- Evidence source: Document context
- Category: Hedging seesaw

Compares evidence across a paragraph, nearby sentences, or the complete document.
