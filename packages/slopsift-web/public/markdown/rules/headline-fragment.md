# ai-style/headline-fragment

An explanatory passage opens with a noun-heavy headline fragment instead of a complete statement.

- Default level: `info`
- Confidence: `low`
- Evidence source: Document context
- Category: Uniform rhythm

Compares evidence across a paragraph, nearby sentences, or the complete document.
