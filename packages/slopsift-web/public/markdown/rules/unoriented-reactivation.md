# reader-first/unoriented-reactivation

A sentence resumes entities or relationships that have already left the active reading context.

- Default level: `info`
- Confidence: `low`
- Evidence source: Dependency graph
- Category: Reading load

Matches grammatical relationships between words, not only their order or part of speech.
