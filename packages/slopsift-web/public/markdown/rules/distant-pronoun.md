# reader-first/distant-pronoun

A sentence opens with "it" or "they" several sentences after the noun it refers to, so the reader must search for the meaning.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Dependency graph
- Category: Reading load

Matches grammatical relationships between words, not only their order or part of speech.
