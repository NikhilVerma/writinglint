# ai-style/mechanical-outline

Repeated bold-label blocks, canned headings, or thematic-break section templates.

- Default level: `info`
- Confidence: `low`
- Evidence source: Document context
- Category: Formatting tells

Compares evidence across a paragraph, nearby sentences, or the complete document.
