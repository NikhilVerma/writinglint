# ai-style/mixed-quotes

Straight and curly double quotes mixed in one document, a paste seam.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Document context
- Category: Formatting tells

Compares evidence across a paragraph, nearby sentences, or the complete document.
