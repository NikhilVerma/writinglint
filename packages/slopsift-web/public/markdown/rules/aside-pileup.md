# reader-first/aside-pileup

Explanations sit in brackets or after dashes instead of being stated directly, with nearby asides treated more severely.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Document context
- Category: Economy

Compares evidence across a paragraph, nearby sentences, or the complete document.
