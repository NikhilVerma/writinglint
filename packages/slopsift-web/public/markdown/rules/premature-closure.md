# ai-style/premature-closure

A summary aside announces that an explanation is complete even though the paragraph immediately continues.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Dependency graph
- Category: Chatbot voice

Matches grammatical relationships between words, not only their order or part of speech.
