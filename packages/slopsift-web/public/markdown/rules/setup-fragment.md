# ai-style/setup-fragment

A noun-rooted fragment (“One thing I wanted to …”) that stages a point instead of making it.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Dependency graph
- Category: Performed voice

Matches grammatical relationships between words, not only their order or part of speech.
