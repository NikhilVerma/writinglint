# reader-first/wh-fragment

A sentence opens with a wh-word but has no main clause, so the reader must guess its subject.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Dependency graph
- Category: Directness

Matches grammatical relationships between words, not only their order or part of speech.
