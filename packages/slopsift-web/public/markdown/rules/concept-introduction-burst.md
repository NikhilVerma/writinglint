# reader-first/concept-introduction-burst

A passage introduces many recurring concepts before the reader has time to absorb them.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Document context
- Category: Reading load

Compares evidence across a paragraph, nearby sentences, or the complete document.
