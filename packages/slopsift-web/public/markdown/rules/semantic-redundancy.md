# ai-style/semantic-redundancy

A nearby paragraph repeats the same content words instead of advancing the argument.

- Default level: `info`
- Confidence: `low`
- Evidence source: Document context
- Category: Chatbot voice

Compares evidence across a paragraph, nearby sentences, or the complete document.
