# reader-first/sustained-buffer-pressure

The document repeatedly adds active entities and relationships faster than it releases or stabilizes them.

- Default level: `info`
- Confidence: `low`
- Evidence source: Dependency graph
- Category: Reading load

Matches grammatical relationships between words, not only their order or part of speech.
