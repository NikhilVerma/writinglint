# ai-style/generation-artifacts

Leftover chatbot citation artifacts (oaicite, turn0search0, …).

- Default level: `error`
- Confidence: `high`
- Evidence source: Text pattern
- Category: Formatting tells

Matches a word, phrase, punctuation pattern, or other directly observable text signal.
