# ai-style/stepwise-sequencing

Formulaic “X then Y” sequencing where “then” narrates an explanation rather than a real order.

- Default level: `info`
- Confidence: `low`
- Evidence source: Dependency graph
- Category: Formulaic transitions

Matches grammatical relationships between words, not only their order or part of speech.
