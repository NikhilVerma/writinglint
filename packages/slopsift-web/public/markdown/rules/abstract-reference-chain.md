# reader-first/abstract-reference-chain

Nearby sentences keep referring to generic problems, shapes, paths, or capabilities instead of naming the concrete facts.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Document context
- Category: Directness

Compares evidence across a paragraph, nearby sentences, or the complete document.
