# ai-style/false-agency

An abstraction is made to act like a person instead of naming the actor.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Dependency graph
- Category: Hidden or false agency

Matches grammatical relationships between words, not only their order or part of speech.
