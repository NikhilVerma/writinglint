# ai-style/undefined-key-term

A central term is introduced indefinitely, repeated across the document, and asked about without being defined.

- Default level: `info`
- Confidence: `low`
- Evidence source: Dependency graph
- Category: Vague attribution

Matches grammatical relationships between words, not only their order or part of speech.
