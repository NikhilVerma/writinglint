# ai-style/vague-declarative

An abstract announcement or vague “this approach…” claim that may need a concrete subject.

- Default level: `info`
- Confidence: `low`
- Evidence source: Document context
- Category: Vague attribution

Compares evidence across a paragraph, nearby sentences, or the complete document.
