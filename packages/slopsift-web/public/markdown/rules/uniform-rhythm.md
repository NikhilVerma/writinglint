# ai-style/uniform-rhythm

Sentence lengths cluster tightly enough to produce a machine-like drone.

- Default level: `info`
- Confidence: `low`
- Evidence source: Document context
- Category: Uniform rhythm

Compares evidence across a paragraph, nearby sentences, or the complete document.
