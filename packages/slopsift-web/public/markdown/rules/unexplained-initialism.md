# reader-first/unexplained-initialism

A repeated initialism appears without a plain-language introduction.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Document context
- Category: Jargon

Compares evidence across a paragraph, nearby sentences, or the complete document.
