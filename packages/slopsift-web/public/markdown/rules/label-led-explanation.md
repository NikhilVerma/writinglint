# reader-first/label-led-explanation

Nearby paragraphs or list items repeatedly open with bold headline fragments before explaining the concrete behavior.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Document context
- Category: Directness

Compares evidence across a paragraph, nearby sentences, or the complete document.
