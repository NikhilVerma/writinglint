# ai-style/evidence-cluster

Several independent slop signals cluster in one paragraph or across the document.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Document context
- Category: Combined evidence

Compares evidence across a paragraph, nearby sentences, or the complete document.
