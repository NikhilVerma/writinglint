# reader-first/fragment-chain

Several nearby prose fragments omit their subjects or main clauses and read like compressed notes.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Document context
- Category: Directness

Compares evidence across a paragraph, nearby sentences, or the complete document.
