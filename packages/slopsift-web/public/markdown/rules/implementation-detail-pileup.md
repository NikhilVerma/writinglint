# ai-style/implementation-detail-pileup

A passage piles up identifiers, qualifications, and exceptions before establishing the normal behavior.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Document context
- Category: Chatbot voice

Compares evidence across a paragraph, nearby sentences, or the complete document.
