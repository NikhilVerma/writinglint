# reader-first/list-without-break

A list starts straight after a finished sentence with no blank line, so it runs into the paragraph.

- Default level: `info`
- Confidence: `low`
- Evidence source: Document context
- Category: Directness

Compares evidence across a paragraph, nearby sentences, or the complete document.
