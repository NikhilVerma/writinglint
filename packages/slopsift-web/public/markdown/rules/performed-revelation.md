# ai-style/performed-revelation

Repeated questions, metaphors, and compressed payoffs make an explanation sound like prepared revelations.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Document context
- Category: Performed voice

Compares evidence across a paragraph, nearby sentences, or the complete document.
