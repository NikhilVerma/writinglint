# ai-style/vague-attribution

A bare, generic subject asserting a “that …” clause. Name who, or cut it.

- Default level: `warn`
- Confidence: `medium`
- Evidence source: Dependency graph
- Category: Vague attribution

Matches grammatical relationships between words, not only their order or part of speech.
