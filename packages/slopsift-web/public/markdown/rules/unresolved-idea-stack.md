# reader-first/unresolved-idea-stack

The document asks the reader to retain several promised explanations or defers one for too long.

- Default level: `info`
- Confidence: `low`
- Evidence source: Document context
- Category: Reading load

Compares evidence across a paragraph, nearby sentences, or the complete document.
