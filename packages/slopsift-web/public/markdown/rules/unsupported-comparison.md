# ai-style/unsupported-comparison

A comparative, superlative, or outcome claim without an explicit benchmark in the phrase.

- Default level: `info`
- Confidence: `low`
- Evidence source: Text pattern
- Category: Vague attribution

Matches a word, phrase, punctuation pattern, or other directly observable text signal.
